# Glossary Reference

| Term      | Source Glossary                | Context                                                                                |
| --------- | ------------------------------ | -------------------------------------------------------------------------------------- |
| Caller    | `docs/development/Glossary.md` | The film create and update rules hold for every caller that may perform them.          |
| Catalogue | `docs/development/Glossary.md` | A film is created under the catalogue, which owns it as an unowned resource.           |
| Movie     | `docs/development/Glossary.md` | The requirement is the film resource's creation and partial update; film is a synonym. |
| Cover art | `docs/development/Glossary.md` | A film's cover follows the catalogue image rule.                                       |
| Action    | `docs/development/Glossary.md` | Creation requires `CreateChild`; an update requires `View` and `EditMetadata`.         |
