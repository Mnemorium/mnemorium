# Glossary Reference

| Term               | Source Glossary                | Context                                                                                             |
| ------------------ | ------------------------------ | --------------------------------------------------------------------------------------------------- |
| Action             | `docs/development/Glossary.md` | Each gallery operation names the action it requires and leaves the who-may rule to `authorization`. |
| Caller             | `docs/development/Glossary.md` | Browse, read and removal are stated for the caller the decision admits.                             |
| Visibility         | `docs/development/Glossary.md` | `is_public` selects `Public` or `Private`; `Public` grants the viewer actions, not moderation.      |
| Position           | `docs/development/Glossary.md` | A new item is appended after the last existing item.                                                |
| Last-modified time | `docs/development/Glossary.md` | Every successful gallery change advances it.                                                        |
| Gallery            | `docs/development/Glossary.md` | The capability defines the collection, its default row and its item ordering.                       |
| Gallery item       | `docs/development/Glossary.md` | The position-aware entry referencing one image or one video.                                        |
