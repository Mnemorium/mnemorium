# Glossary Reference

| Term                 | Source Glossary                | Context                                                                                                                     |
| -------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| Action               | `docs/development/Glossary.md` | `View`, `Stream` and `Download` are the three actions the routes decide; none of them is defined here.                      |
| Content Type         | `docs/development/Glossary.md` | The stored MIME type a content response carries; the capability never reclassifies it.                                      |
| Caller               | `docs/development/Glossary.md` | Every content request is decided for the caller its session token resolves.                                                 |
| Resource             | `docs/development/Glossary.md` | A decision addresses the file resource the typed asset resolves to, not the route.                                          |
| Authorization parent | `docs/development/Glossary.md` | The file's parent chain is what makes a catalogue cover or a gallery item reachable; the capability never states the edges. |
| Who-may rule         | `docs/development/Glossary.md` | The capability names the action its route decides and leaves who holds it to `identity/authorization`.                      |
