# Glossary Reference

| Term         | Source Glossary                | Context                                                                                                                  |
| ------------ | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| Action       | `docs/development/Glossary.md` | `View`, `Stream` and `Download` are the actions the content routes name and decide per request.                          |
| Content Type | `docs/development/Glossary.md` | The stored MIME type a content route serves with the bytes; the routes never reclassify it.                              |
| Grant        | `docs/development/Glossary.md` | A grant change is what the removed twelve-hour credential could not observe, because the decision ran once at mint time. |
| Who-may rule | `docs/development/Glossary.md` | The new capability names the action each route decides and leaves who holds it to `identity/authorization`.              |
