# Glossary Reference

| Term                   | Source Glossary                | Context                                                                                                                         |
| ---------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| Caller                 | `docs/development/Glossary.md` | Every music read and write is stated against the caller's `Discover`, `View`, `CreateChild`, `EditMetadata` or `Delete` action. |
| Catalogue              | `docs/development/Glossary.md` | An album and a group are created under the catalogue; a playlist is created under the library.                                  |
| Last-modified time     | `docs/development/Glossary.md` | A successful playlist metadata change advances it, including a change that stores an equal value.                               |
| Partial representation | `docs/development/Glossary.md` | An album or group page item carries only its identifier, name, cover and links.                                                 |
| Visibility             | `docs/development/Glossary.md` | A playlist's `is_public` flag sets `Private` or `Public`, and discovery follows it.                                             |
