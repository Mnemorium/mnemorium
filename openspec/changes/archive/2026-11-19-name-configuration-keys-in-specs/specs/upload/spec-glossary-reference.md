# Glossary Reference

| Term           | Source Glossary                | Context                                                                                     |
| -------------- | ------------------------------ | ------------------------------------------------------------------------------------------- |
| Upload session | `docs/development/Glossary.md` | Session begin, expiry and reaping name the settings that bound the session's size and life. |
| Content Type   | `docs/development/Glossary.md` | The begin request carries a declared content type the setting does not affect.              |

| Staged content | `docs/development/Glossary.md` | Expiry and reaping remove staged content; the settings bound when and in what batch.        |
| Caller         | `docs/development/Glossary.md` | The session and its staged content belong to the caller who began it.                       |
