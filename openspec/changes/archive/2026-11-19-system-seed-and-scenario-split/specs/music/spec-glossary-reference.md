# Glossary Reference

| Term                   | Source Glossary                | Context                                                                                            |
| ---------------------- | ------------------------------ | -------------------------------------------------------------------------------------------------- |
| Caller                 | `docs/development/Glossary.md` | Every scenario acts for an authenticated caller; who may curate stays the authorization statement. |
| Partial representation | `docs/development/Glossary.md` | The album and group collections keep the partial item shape the API declares.                      |
| Catalogue              | `docs/development/Glossary.md` | An album, a medium, a recording and a group live under the catalogue and have no owner.            |
| Visibility             | `docs/development/Glossary.md` | A playlist's public or private visibility is what the collection scenarios read.                   |
| Last-modified time     | `docs/development/Glossary.md` | A metadata replacement advances the playlist's last-modified time.                                 |
| Position               | `docs/development/Glossary.md` | A track is addressed by its medium index and its index in the medium, never by a surrogate.        |
| Cover art              | `docs/development/Glossary.md` | A track carries no artwork; the album's cover is the proof the cover-art capability owns.          |
| Default album          | `docs/development/Glossary.md` | The seeded album the catalogue never writes; the glossary gains the term with this change.         |
| Default group          | `docs/development/Glossary.md` | The seeded group that owns the default album; the glossary gains the term with this change.        |
