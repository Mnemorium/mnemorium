# Glossary Reference

| Term                   | Source Glossary                | Context                                                                                                                        |
| ---------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Seed profile           | `docs/development/Glossary.md` | The named fixture a `test-seed` boot applies; the glossary gains the term with this change.                                    |
| Stored file            | `docs/development/Glossary.md` | The record the stored-file collection lists, and the row the suite reads through it instead of the datastore.                  |
| Library root           | `docs/development/Glossary.md` | The seeded files live under it at root-relative paths, and no case addresses a file by an absolute path.                       |
| Upload session         | `docs/development/Glossary.md` | A case owns its session, staged content and completed file; only a whole-directory or startup-setting claim keeps a container. |
| Caller                 | `docs/development/Glossary.md` | The collection returns the stored files the caller may discover, so a case states an action and never who holds it.            |
| Resource               | `docs/development/Glossary.md` | The ingest now writes the `FILE` resource a found file needs to be reachable by identifier.                                    |
| Partial representation | `docs/development/Glossary.md` | The film and album collections the seeded rows are browsed through keep the partial shape the API declares.                    |
| Catalogue              | `docs/development/Glossary.md` | The system profile seeds catalogue rows, and each module owns an identifier block within the band.                             |
| Cover art              | `docs/development/Glossary.md` | The reworked cover-art module proves the scope and refusal rules against seeded catalogue and playlist rows.                   |
| Action                 | `docs/development/Glossary.md` | A case proves the effect of a decision, while which caller holds the action stays the authorization capability's statement.    |
