# Glossary Reference

| Term          | Source Glossary                | Context                                                                                   |
| ------------- | ------------------------------ | ----------------------------------------------------------------------------------------- |
| Admin         | `docs/development/Glossary.md` | The non-root account that administers Standard Users and is itself untouchable by a peer. |
| Standard User | `docs/development/Glossary.md` | The account an Admin creates and administers.                                             |
| Root Admin    | `docs/development/Glossary.md` | The account that reads any resource and alone administers Admins.                         |
| Gallery       | `docs/development/Glossary.md` | The owned collection whose deletion and item operations carry the migrated denial cases.  |
